# Titanic Survival Prediction Using Machine Learning

## 1. Project Overview

This project focuses on analyzing the Titanic passenger dataset and predicting passenger survival using Machine Learning algorithms.

The project involves data preprocessing, exploratory data analysis, data visualization, and the implementation of different classification algorithms.

## 2. Dataset Information

The Titanic dataset contains information about 891 passengers and 15 original columns.

It includes information such as passenger class, gender, age, fare, family members, embarkation location, and survival status.

The dataset is loaded using the Seaborn library in Python.

## 3. Project Objectives

- Analyze the Titanic passenger dataset.
- Perform data cleaning and preprocessing.
- Handle missing values.
- Perform exploratory data analysis (EDA).
- Visualize important patterns and relationships.
- Apply different Machine Learning classification algorithms.
- Compare model performance using accuracy and classification reports.

## 4. Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- GitHub

## 5. Data Preprocessing

The following preprocessing techniques are used:

- Handling missing values.
- Removing unnecessary columns.
- Label encoding of categorical variables.
- Feature scaling using StandardScaler.
- Detecting and handling outliers using the IQR method.
- Splitting the dataset into training and testing sets.

## 6. Exploratory Data Analysis

The project includes:

- Survival count visualization.
- Age distribution analysis.
- Fare distribution analysis.
- Gender-based survival analysis.
- Passenger class survival analysis.
- Boxplots for outlier detection.

## 7. Machine Learning Algorithms

Four classification algorithms are implemented:

1. Decision Tree Classifier
2. Logistic Regression
3. Support Vector Machine (SVM)
4. Random Forest Classifier

## 8. Model Performance

The recorded model accuracy results are:

| Algorithm | Accuracy |
|---|---:|
| Decision Tree | 76.54% |
| Logistic Regression | 82.12% |
| Support Vector Machine | 83.24% |
| Random Forest | 79.89% |

Among these recorded results, Support Vector Machine achieved the highest accuracy of 83.24%.

## 9. Model Evaluation

The models are evaluated using:

- Accuracy Score
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 10. Conclusion

This project demonstrates how Machine Learning can be used to analyze passenger information and predict survival outcomes.

Different classification algorithms were implemented and compared. Support Vector Machine achieved the highest recorded accuracy among the four models in this experiment.
